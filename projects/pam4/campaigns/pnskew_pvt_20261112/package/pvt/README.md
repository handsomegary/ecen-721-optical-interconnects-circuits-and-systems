The 27 small-signal cases cross TT, SS, and FF with −40, 25, and 85 °C and 0.81, 0.90, and 0.99 V. The cross-product keeps voltage and temperature sensitivity visible independently of process. `cases/` contains the generated Spectre decks, per-case input SHA and line diffs, and `pvt_ac_matrix.json`. Diffs are relative to `cases/nominal_parent.scs.txt`. Only the model include, simulation temperature and AFE VDD may differ. The nominal reconstruction uses the original `p6_bench.py` topology with the 96 exact native device cards from the published focus55 `candidate.scs` (`44c3fe504753a4db479c861797ee8fbe09d3e70ab9fedf273272870c9a6e9bfc`). The standalone r3 AC fixture was regenerated. Restoring its sole original model root gives the archived focus55 optimizer bench SHA-256 ee2035953b1938121b2c0730206bbff29d2cf05e0a040ea77b281ab354f8a1ca. The packaged reference records the reconstruction inputs and their hashes. The archived VM result for this exact TT optimizer bench records +6.47995 dB at the CTLE output, +5.34159 dB at tracking lane 0 (both 56 GHz versus 1 kHz), and 10.08 mW DC AFE supply power. Use it as a nominal sanity check before comparing corners. The four tracking and four holding primary transmission-gate lanes, component values, bias voltages and native geometry are held fixed. Settings reproduce the focus55 optimizer's 1 kHz–150 GHz AC sweep at 50 points/decade and frozen-track 1 MHz–56 GHz noise sweep at 40 points/decade.

`model_preflight.py` verifies the private model files against the archived VM fingerprints, including the original `shrink` wrapper. TT selects the original `tt`. SS and FF use the exact published `la5_foundry_corners.scs` route with only its private root token substituted. The selected sections, matching process route, and scale declaration are checked before execution. The collector checks the effective `scalefactor=0.9` against the actual Spectre log. SF and FS are outside this matrix because the project lacks an authenticated route for them. No foundry model body is included. The private kit on Olympus remains to be checked there.

For each case the collector records absolute gain at 1 kHz and 56 GHz, 56 GHz gain relative to 1 kHz, and the absolute peak gain and frequency on the saved AC grid. It reports CTLE output and frozen tracking lane 0 separately. The 20 dB at 56 GHz limit is evaluated against the CTLE output's low-frequency-relative gain. DC reports AFE supply power, common modes, rail clearance, and representative tail operating-point fields when present. Noise is the integrated differential voltage at the frozen tracking node. The 1 kHz gain is a small-signal near-DC reference and the noise result excludes sampled noise folding. Preserve the compact JSON and hashes on readback.

The integrated quiet follow-up uses zero skew at TT/25 °C/0.90 V from the PN-skew control and adds SS/85 °C/0.81 V and FF/−40 °C/0.99 V using the genuine admitted r5 deck with the same r3 AFE. Only process selection, temperature, and the AFE `XVs` supply change. Other rails and ideal clocks, stop/save, loading, 7-bit quantizer, and fixed FFE are identical. Use the original frozen validation scorer for both sampling points. The summary compares held margins, raw-held FFE symbol errors, ideal-7-bit FFE symbol and Gray bit errors, MSE, and clipping. No corner is declared the worst solely from its label. The two transient endpoints sample this comparison and no transient-noise PVT sweep is included.

AC/DC/noise allocation is one classic Spectre CPU, 4 GiB, and 30 minutes per case with a 20-minute solver timeout. The planning estimate is 10–120 seconds and roughly 1 GiB peak RAM per case. Time and RSS need actual receipts. The quiet corner transients use the same 29.414 ns and save list as the quiet skew control. Use the measured control time and raw size as the scheduling estimate for each endpoint. These checks were prepared offline. No new result or model availability on Olympus was measured locally.

Run the offline checks from the package root with `python3 -B -m unittest discover -s pvt -p test_pvt.py -v`.
