# ECEN 721 #6｜LP14 補掃與非理想電感

## 對 DIAG NEXT 的處置

- **Replica**。TT、FF 的 cb0、cb2 各補一次 STB，沿用原 iprobe、偏壓與觀測點。掃頻 1 Hz–20 GHz，每十倍頻 100 點。原生 GM 有效時沿用 PM ≥60°、GM ≥10 dB，並核對掃頻與原生穩定狀態。沒有 GM 時留空。只有原生穩定、PM 與複數資料相符、同一非零工作點、唯一向下 unity 交越、正實軸無超出 0.316 的取樣交越且高頻持續衰減時，標記為取樣頻帶篩選通過。完整複數資料與頻帶末端數值隨報告保存。
- **Beta multiplier**。維持原電路。進入下一階段的判準為在同一非零工作點、啟動支路退出後，Spectre 無不穩定判定，1 Hz–20 GHz 延伸篩選顯示全帶 `max |T|<1`、無 unity 交越且高頻衰減，並結合三角落已量得的啟動、重啟及 ±5 µA 擾動恢復。DIAG NEXT 已有這些證據，`max |T|` 約 0.50，`min |1−T|` 約 0.495，20 GHz 時 `|T|` 約 0.014–0.016。歷史 10 dB 篩選保留為 review。正式局部穩定度需補上可辨識偏壓相關模態的閉環極點證據，或核對開環 RHP 極點數及完整 Nyquist 繞行。既有脈衝打在 GMSR_REF，驗證的是整合偏壓的恢復。 [Spectre return-ratio 方法](https://kenkundert.com/docs/cd2001-01.pdf)
- **XT2**。本階段維持 Vb2 = 0.580 V。SS cb2 的滿／半擺幅正規化增益差 0.10 dB，約為 1.15% 振幅差，可以接受為繼續 AC 篩選的依據。以原案 17、18 的 raw 做逐路 clock-fall 配對，報告斜率、正規化差值與移除仿射分量後的殘差 RMS、P95、最大值。原報表的 region 時間占比與負裕度樣點比例各有定義。待逐路殘差和長案確認取樣失真及 SER。

## 批次 A｜Replica 與電感 pilot

| 索引 | 用途 |
| --- | --- |
| 0–3 | TT／FF，各 cb0／cb2，補 20 GHz replica |
| 4–17 | 三角落 r3 基準與四組同路徑理想驅動 |
| 18–25 | 兩顆理想 120 pH 的原生驅動對照 |
| 26–33 | 120 pH，系列支路 Q56 = 15、無損 LC SRF = 150 GHz，SS cb0／cb2、TT cb2、FF cb0 |
| 34–39 | 120 pH，系列支路 Q56 = 8、無損 LC SRF = 110 GHz，SS cb0／cb2、FF cb0 |

只改共用驅動的兩顆 120 pH peaking coil。用系列 L–R 與並聯 Cp 做敏感度，50 Ω 延遲路徑沿用。兩組 R／Cp 分別為 2.815 Ω／9.382 fF、5.278 Ω／17.445 fF。併入 Cp 後 56 GHz 的端口有效 Q 約為 12.90、5.89。系列 R 同時作用於 DC 與 AC，未量實際電感 DC 電阻或頻散。原生 L120／1934 Ω／4P1N 偏壓、Rs = 25 Ω、Vb2 = 0.580 V 沿用。

P/N 兩個 AC 激勵合成 Hdd 和 CM→DM。同路徑理想驅動為 56 GHz 的 2 dB 損失對照，原生理想電感用來量被動件的增量影響。功耗以同角落原 r3 的供電總和為基準，cb0／cb2 預算為 +10／+14 mW。另報 7–56 GHz tilt、群延遲、噪聲、支路 DC 電流、drain 電位、XT2 裕度，以及相對 **實測 Iref ×14** 的伺服誤差。若 DC 電阻帶來 tracking 問題，另提 replica 負載電阻敏感度。此 pilot 尚未涵蓋電感 mismatch、L 容差或 EM 模型。

## 批次 B｜端點與細碼，等待 A 結果

1. **端點**。用 A 選出的電感模型，在 SS／TT／FF 測 0、−4.464 ps、+4.464 ps。零點走 cb0，端點比同硬體未補償、實體碼補償及同路徑理想驅動，先檢查兩極性是否有足夠的延遲涵蓋、56 GHz 增益、CM→DM、功耗及頻帶內色散。以複數傳輸對 7–56 GHz 的相位作加權線性擬合，另報 56 GHz 相位延遲、去除擬合後的殘餘及靠近零交越處的有效性。先用 r1 通道與波形關聯這些 AC 指標和 FFE 後 SER。
2. **細碼**。從歷史端點 0.56 ps 步階下手，在兩端接縫插入相鄰路徑間的 1/3、2/3 配置。例 6/16 → 6⅔/15⅓ → 7⅓/14⅔ → 8/14，另一端鏡像。TT 量完整相鄰碼；SS、FF 先量兩個接縫、零點、相鄰碼和正負端點。報告帶權延遲步階、單調、路徑切換不連續和剩餘 skew。依既有條件把最大步階收進 0.50 ps；0.25 ps 殘餘是待核定的設計目標。用可接線的全域碼表驗證實體相鄰路徑，再送長案。
3. **電感補強**。主線跑端點前先補 TT cb0、FF cb2 的零 skew，並補 L ±10% 及兩腿反向偏差的最緊條件。公差數值是敏感度選點，待實際 PDK／EM 資料替換。

## 批次 C｜時域 SER，等待 A、B 結果

先跑 TT 的短無雜訊案，核對 0、±0.25、±0.5 UI 及劣化開始附近 ±0.25～±0.375 UI 的細掃。把接縫兩側的殘餘 skew 納入短案。用同樣的 0.4 Vppd、雙極通道、8 相取樣、理想 7-bit 量化及既有凍結 17-tap FFE。以獨立零 skew 訓練段決定共同取樣相位，凍結後用未見的 payload 計分。實際碼由已知訓練序列在候選碼間作 pre-FFE 誤差搜尋，碼相同分數時使用固定的 tie-break，再凍結碼做獨立 payload。真實注入的 skew 只用於離線標記及理想補償對照。

短案先比較 r3／r5 零 skew 基準、整合零 skew、同硬體未補償、實際訓練選碼、及理想校正上限。分別保存 primary／secondary 的 FFE 前後錯數、樣本數及 held 電平。先送一組配對噪聲 smoke 核對時間、seed 和收集，再擴到既有 20 組種子，補償前後使用同一組種子。呈現每 seed 的配對 ΔSER 和分布，三角落用各自的零 skew 對照，另外列出 secondary 的既有雜訊錯誤。長案目前每案估 1–4 小時，依 smoke 更新 CPU、記憶體、walltime 和批次大小。SER 驗收門檻在長案提交前核定。
