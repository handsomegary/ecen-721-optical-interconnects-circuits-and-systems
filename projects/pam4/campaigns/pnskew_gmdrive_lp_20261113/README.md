# PN skew 補償 GMDRIVE LP：低功耗驅動候選（2026-11-13）

第七版。GMDRIVE 首批中只有 cs16 低於 2 dB，但功耗增加 14 mW，所以 Codex 提出三個低功耗候選。使用者核定功耗預算：以各 corner 的原 r3 AFE 為基準，單組啟用最多 +10 mW，雙組啟用最多 +14 mW（工程預算；課程未設上限）。全包 188 案，使用者批准 pilot 0–27（SS/85 °C/0.81 V 短路徑）。
