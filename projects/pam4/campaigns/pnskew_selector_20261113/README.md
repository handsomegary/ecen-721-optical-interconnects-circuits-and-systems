## 結果（46/46 完成）

- AC 耦合的理想選路：−0.34 dB、±5.249 ps，耦合本身沒有問題。

- 「只留導通支路」與「完整 mux」幾乎相同，所以損失來自串聯 Ron，不是未選路徑的 Coff。
