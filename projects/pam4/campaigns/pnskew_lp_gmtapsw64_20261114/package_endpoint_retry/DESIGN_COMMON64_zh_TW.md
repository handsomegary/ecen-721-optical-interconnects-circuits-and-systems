# ECEN 721 #6｜Split64 共同碼表與實體 Vb1

## 設計決定

共用 **565 mV Vb1**，Vb2 維持 580 mV，保留 Split64、coarse3 固定延遲線和原 LP14 驅動。2% 舊中心電流差繼續當診斷。新中心每腿 2.333 mA、較舊中心低 3.43%，已量 Hdd 相對對照 −1.87 dB、功耗增量 +8.12 mW、XT2 最小裕度 +9.63 mV 且原生 region 2。最終以各碼 XT2、增益和功耗判定，另報路徑內總尾電流誤差與峰對峰。 [CENTER64 SS 實測](https://github.com/<owner>/ecen-721-optical-interconnects-circuits-and-systems/blob/4939c70d84d43af44c2e71fe987d9f25b9911806/projects/pam4/campaigns/pnskew_lp_gmtapc64_20261114/results/lp_gm_center64_ss_primary.json)

實體主候選是 **375 Ω／14.125 kΩ、2 pF**，由既有理想 580 mV Vb2 供應。空載 565 mV，Rth 約 365 Ω。按 SS Split64 的 2.84 µA 負載估計，受載約 563.96 mV。以量得的 Vb1、分壓負載、各腿尾電流、XT2、Hdd 與噪聲決定是否維持這組阻值。Vb1 的超過 ±2 mV 偏差另標診斷。舊 1k／57k 空載 570 mV，已知 SS 受載約 567.35 mV，作既有比較。此包量 Vb2 所帶的被動網路，上游 Vb2 驅動阻抗、供電開啟與實體寄生留到動態版。

## 靜態量測和碼

- **SS 理想對照**。補齊 q=±3…±11 與 ±56…±60，重測中心與 q=±12、±32、±52 的相同權重。三個固定 bank 的網表不變。TT、FF 先驗 0、±1、±2、±32 與 ±56…±60。
- **實體偏壓先驗同一組三角落代表碼**。同網路、同權重的最小負載對照隨每個碼測量。報實體 Vb1 對同碼理想值、兩方向 4.464285714 ps 與 Hdd、CM→DM、XT2 native region。2 dB 全碼篩選用該碼在各自擬合延遲下的相同注入。±4.464 ps 另報固定條件，與同硬體零校正比較。
- **共同碼表**。三角落都實測同一物理網路的 55 個主候選。q=0、±1…±12、±16／20…52、±56…±60；按量得的缺口加 ±14／18…54。以每角落的同硬體零碼為基準量 7–56 GHz 帶權延遲。保留一套在 SS／TT／FF 都嚴格單調、每步 ≤0.50 ps、含零碼且兩邊至少達 4.464 ps 的碼表。不合格中間碼可略過，前提是同樣順序仍符合步階、RF、功耗及 XT2。端點另比對 ±4.464 ps 的 Hdd 與未補償，以及同權重 oracle。每碼保存兩份 P/N DC 的原生 XT2 region 與 VDS−|VDSAT|。給硬體的靜態碼對應 split64_control_words.json 內的三組尾管 mask，順序以實測表為準。

## 動態驗證提案

靜態表通過後，才生成同網表的短切碼案。將選定字的尾管使能電壓轉成可實作的 PWL，保留實體 TG／INV、tap、分壓器與取樣通路。先量 SS 的零碼↔±1、+1↔+2，另量 SS／FF 的正負端點互換，選最差中段再量 0.4／0.2 Vppd 固定碼。+1→+2 雖只差 1/64，仍可能同時改變三個實體致能訊號。以相同目的碼、相位對齊資料的穩態作對照，量 Vb1／Vb2、各 bank／各腿電流、XT2 原生 region 與裕度、八路 held 值和恢復時間。切碼段保留 8–10 ns 初始恢復窗，按實測延長。名義 RC 5τ 約 3.65 ns。已有的全幅短暫 triode 與壓縮結果作既有參考。動態案估 1 CPU、2–8 分鐘／案，另以首案更新原始檔大小。正式 C0／C1／C2 等共同碼表和切碼檢查。
