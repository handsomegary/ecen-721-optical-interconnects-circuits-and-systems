首版 cell 與控制
每腿 4 個串聯的 L/2–C–L/2 T 型低通 ladder section（串聯半電感、中心 shunt C，再串聯半電感）。
每節 L 總 65 pH，理想電感 ESR 總 1.5 Ω。中心固定 12 fF 加 6 個可開關的理想電容
1.25/2.5/5/10/20/40 fF。上電前選好靜態 gate control，測試期間碼固定。
每個 shunt C 用 native NMOS/PMOS transmission gate，L=30 nm、W 各 1 μm、nf=multi=1。
逐字複用已入場的 B0_SN0p、B0_SP0p 幾何卡，替換 instance 與四個 terminal；保留寄生 flags。
PMOS bulk 用 PNC_VDD，NMOS bulk 接 ground。1 TΩ 將浮動 cap node 拉到原 X_cm=.7 V。
TG 靜態偏壓在原 PVT rail，0.81 V 時 N-overdrive 可能不足，尤其需看 PMOS 導通與非線性。
這是具 native switch 的 schematic hybrid；L/C/ESR 是理想元件模型。passive Q、layout/EM、
ESD/termination、數位控制與低負載量測電路留待實作。未經 Spectre 或 PEX。
粗碼觀察 0、4、8、16、24、32、40、48、56、63，細搜較佳粗碼±3。P=k，N=63−k。
粗細是搜尋階層，實體先共用一個 6-bit bank。電容總和固定並不能固定共同延遲。
binary carry 需驗證 DNL，若非單調可用實測可用碼集合，缺區間時改分段 thermometer 或加獨立 fine bank。
每角落量全部 64 個互補碼對，signed differential coverage 要觸及 ±4.464 ps。最大實際相鄰 gap
比平均 LSB 更重要。待批准預算：局部 gap ≤0.25 ps 讓最接近碼的量化上界 0.125 ps，
另保留 detector/漂移各約 0.075/0.05 ps。q≤0.5 ps 僅是理想均勻碼下的必要條件。

模型先篩選
behavioral_ladder.py 用等效 C 模型（16 個 5 fF 步階；與 6-bit native bench 使用不同 code index）
檢查 Rs、CL、ESR。50 Ω／50 fF／ESR 1.5 Ω 時，15/0 在 56 GHz 有 5.189 ps，
14–56 GHz 的 phase delay 變動 3.376–8.737 ps。已知目標時理想最佳碼對頻帶最差殘差仍 2.080 ps。
因此首版 LC 是供篩選的實體候選。單頻 delay 過關不足以展開整合。若 sparse bench 的複數傳遞顯示
明顯 dispersion 或損失，先交付該結果，改設計寬頻均化與端接。先確認 actual r3 load、最差功耗、
headroom、噪音及 corner range，再決定做完整碼表。初版是否能達範圍與殘差仍待量測。

前景校正與硬體接口
校正讀取 trim 後 X_ip/X_im。先量兩段 224 UI，再用後兩段 224 UI 驗證。原驗證 stimulus
的前 896 UI 落在原 2048-symbol scoring 窗之前。以既有已知 transition-rich 前綴為 pilot，
以相同時間基準在兩腿擷取 32 樣本/UI，頻率取 7/14/21/28/35/42/49 GHz。
分析使用反相 N 的相對複數傳遞、phase unwrap、斜率和各頻相位殘差，DC 與 gain 另報。
分兩段求互功率比以降低噪音；真值、payload label、FFE 分數都不進選碼函式。
觀測前台的實作是高阻抗對稱 tap 和共用 sampler，重複 pilot 時步進相位再做等效時間量測。
這次 Spectre 用直接節點保存代表該觀測。實體 tap 的負載、offset、噪音、共享時基偏差需另驗。
56 GHz 等於單點/UI 的 Nyquist 頻率，因此估測器用 49 GHz 以下多頻，不從單相位 Nyquist 樣本估相。
pilot 的純資料長度共 8 ns，加 startup、每碼 settle 與多次試碼；量到實際有效樣本再定硬體成本。
獨立窗口不穩定、幅度不足或殘差過大時回報 NO_LOCK，保留觀測。偏置誤差與噪音亦可能使斜率錯估。
驗證下一步加入 zero-skew + gain mismatch、外加 CM、共同相位跳變、tap skew、上下電及反向初值。
目前內建的是雙窗 readback 和無真值的碼選擇，這些額外擾動為下一個需批准的試驗。

預先寫定的判讀（所有新數字待使用者批准）
1. 校正殘差草案 ≤0.25 ps（斜率與跨頻 phase-equivalent 取較大），獨立窗口 repeatability ≤0.075 ps，
   每腿至少 20 μV 複數 pilot 振幅。首輪 7–49 GHz，56 GHz 由 AC 和殘差診斷補證。
2. 原同負載 bypass 為 AC 基準。草案 56 GHz |Hdd| 減損 ≤1.0 dB、7–56 GHz 不接受明顯窄帶峰谷，
   先報每頻複數 Hdd/Hdc、phase delay、group delay 與源端 admittance，保留相位與幅度。
   CM 轉換以同 reference 複數差正規化，草案 |ΔHdc|/|Hdd0|≤0.1。靜態噪音報 Vrms 和方差差，
   功耗量 AFE/trim/靜態 driver rail；整合報原 rail 與新增 rail。噪音與功耗先報數值，沒有硬性合格線。
3. 零 skew 以新增硬體和原無 cell 比，報主／次 FFE error、MSE、clipping、眼間距與共同延遲。
   SER +1 pp 是上輪劣化標籤，沿用作本次診斷。已小於零的 gap 只報電壓差。補償後與
   同硬體同 seed 零 skew 比得到增量，再與原無 cell skew 及數學 oracle 並列。
4. 9 點、兩側 0.28125/0.3125/0.34375 UI 補點。殘差 stress 固定已選碼、施加
   target−pilot residual 的額外差動 PWL time shift（±0/0.25/0.5/1 ps）。用輸出 pre-mix pilot
   核對實際達到的殘差，按量測值歸類，禁止因目標標籤就宣稱達到。
5. 雜訊在 0/±0.5 UI，使用 1001–1020 同 seed，比較未補償與同硬體零點，分主/次取樣報每 seed、
   mean/range 及不完整清單。同 seed 是配對 ID，adaptive solver 的噪音軌跡可能不同。
   SS/85°C/.81 V、FF/−40°C/.99 V 兩端各加零 skew 與±0.5 UI；不重新訓練 FFE。
6. 既有 2048-symbol payload 用來配對本輪，不構成獨立最終 holdout。所有缺資料或 NO_LOCK 分列。
   以原方案「新增 Hdc 低於預算」作工程篩選；實體 monitor、完整 ADC、功耗及課程符合性均未驗證。
